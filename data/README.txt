Bộ dữ liệu Dunnhumby "The Complete Journey" (https://www.dunnhumby.com/source-files/).

Thư mục này có sẵn 7 file dùng trong đồ án:
  transaction_data.csv, product.csv, hh_demographic.csv, campaign_table.csv,
  campaign_desc.csv, coupon.csv, coupon_redempt.csv

File thứ 8 là causal_data.csv (khoảng 600 MB, dữ liệu trưng bày / tờ rơi theo tuần).
Đồ án không dùng file này nên không đóng gói kèm. Nếu cần, chép causal_data.csv vào
đúng thư mục này; không notebook nào bắt buộc phải có file đó.
